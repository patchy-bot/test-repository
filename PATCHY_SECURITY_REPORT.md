## 🔧 Security Fixes Provided


### 1. web2/exec/app.py
**Vulnerability:** CODE_INJECTION  
**Confidence:** HIGH  
**Breaking Changes:** No

**Explanation:** Removed exec() entirely and replaced with an AST-based safe evaluator. We define a whitelist of AST node types and allowable variable names, then parse, validate, compile, and evaluate the user expression in a sandboxed context with no builtins.

**Security Notes:** This approach limits operations to simple arithmetic on predetermined variables. For more complex logic, consider using a dedicated sandbox or domain-specific language.

**Additional Dependencies:**
- ast

**Testing Recommendations:**
- Submit valid and invalid expressions to /eval
- Attempt to inject malicious nodes (e.g., '__import__') and ensure rejection
